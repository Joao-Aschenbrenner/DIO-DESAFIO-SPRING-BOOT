Envie um áudio ou escreva um comando. O Budget AI transcreve, interpreta a intenção com Spring AI, chama as ferramentas da aplicação e registra ou consulta transações persistidas localmente.

Java 21 Spring Boot Spring AI NVIDIA Nemotron Omni Tool Calling JPA + H2

O que este projeto demonstra

O foco do desafio é conectar IA a regras e funções reais sem colocar a lógica de negócio dentro do modelo.

  • Áudio para texto com NVIDIA.
  • ChatClient interpreta a intenção.
  • Tools chamam os casos de uso Java.
  • Dados são persistidos localmente.
  • Resposta pode voltar em voz.
